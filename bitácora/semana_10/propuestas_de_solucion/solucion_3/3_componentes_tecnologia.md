# 3. Componentes y Tecnología

| Componente | Función |
| :-- | :-- |
| Celda de carga de 50 kg | Mide el peso del contenedor y de cada bolsa. |
| Módulo HX711 | Digitaliza la señal de la celda de carga. |
| ESP32 DevKit | Calcula el peso, detecta cada nuevo ingreso y envía los datos por Wi-Fi. |
| Sensor ultrasónico HC-SR04 | Mide el nivel de llenado para estimar el volumen. |
| Plataforma rígida y estructura de soporte | Sostiene el contenedor sobre la celda de carga. |
| Fuente de alimentación USB de 5 V | Alimenta el sistema. |
| Pesos de referencia | Calibración de la balanza. |
| Servidor, base de datos y página web (HTML) | Almacenamiento de registros y dashboard. |

La lista completa de materiales está en la [semana 11](../../../semana_11/9_lista_materiales.md).
