# 17. Riesgos, supuestos y asuntos por validar

| Riesgo o incertidumbre | Mitigación |
|---|---|
| Falta de balanza adecuada | Validar y disponer de un equipo apropiado para el flujo |
| Sin acceso a registros reales | Empezar con prueba controlada y declarar claramente su alcance |
| Falta de responsable de medición | Acordar calendario con encargado y sustituto |
| Contaminación de materiales | Etiquetar, observar y registrar rechazo |
| Pérdida de origen al mezclar | Medir antes del acopio conjunto |
| Desconocimiento del destino | Registrar como pendiente, no valorizado |
| Operadores con poco tiempo | QR, formulario breve y capacitación |
| Cambios de distribución física | Zonas configurables |
| Registros faltantes | KPI de cobertura y alertas simples |
| Software sin mantenimiento post-Capstone | Manual, credenciales institucionales, transferencia y documentación |

## Preguntas clave para la contraparte

1. ¿Qué residuos se separan realmente y dónde?
2. ¿Cuáles tienen gestor y ruta de disposición documentada?
3. ¿Quién pesa, cuándo y con qué equipo?
4. ¿Qué espacio autorizan para la medición piloto?
5. ¿Cómo se producen los retiros y existen comprobantes?
6. ¿Quién administrará la plataforma a futuro?
7. ¿Qué restricciones de presupuesto, conectividad, acceso y datos existen?

**Nota normativa:** el sistema es una herramienta interna de gestión; no se presenta automáticamente como plataforma de cumplimiento regulatorio o declaración REP. Deben validarse las condiciones sanitarias y operativas si se instala infraestructura o se reciben residuos externos.
