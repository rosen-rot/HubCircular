# 3. Componentes y Tecnología

| Componente | Función |
| :-- | :-- |
| Sensor infrarrojo de barrera (emisor y receptor) | Detecta cada objeto que pasa por la abertura del contenedor. |
| Sensor ultrasónico HC-SR04 (opcional) | Mide el nivel de llenado del contenedor. |
| ESP32 | Cuenta los ingresos y envía los datos por Wi-Fi. |
| Fuente de alimentación de 5 V | Alimenta el sensor y el microcontrolador. |
| Servidor y base de datos | Recibe y almacena los conteos. |
| Página web (HTML) | Dashboard con los indicadores. |
