# 18. Entregables y matriz de cumplimiento

| Requisito de la ficha | Respuesta HubCircular | Evidencia prevista |
|---|---|---|
| Prototipo de registro/seguimiento | Formularios QR, lotes, movimientos e historial | Demo web y pruebas de transacciones |
| Metodología de medición | Protocolo con pesaje neto y calendario | Manual + mediciones del piloto |
| Panel de indicadores | Dashboard ambiental y filtros | Indicadores y registros que los sustentan |
| Datos periódicos/comparables | Estandarización, omisiones y cobertura | Comparaciones entre períodos |
| Detectar oportunidades | KPIs + recomendaciones explicables | Una mejora documentada con datos |
| Uso sencillo por Hub | UX móvil y capacitación | Test de tareas, tiempos y errores |

## Resultado esperado

Una plataforma web funcional con mediciones, trazabilidad, indicadores y resultados de evaluación, acompañada de una metodología que pueda utilizar el equipo del Hub. La eficacia debe sustentarse en evidencias del piloto, no solo en capturas de pantallas.
