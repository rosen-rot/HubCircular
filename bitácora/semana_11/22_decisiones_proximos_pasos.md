# 22. Decisiones finales y próximos pasos

## Decisiones recomendadas para el grupo

- Usar un nombre único: **HubCircular**.
- Enfocar el alcance en el **Desafío 04** y su flujo piloto.
- Crear una **única web responsive** con roles y QR de identificación.
- Incorporar trazabilidad por lotes, retiros y evidencia de destino desde el MVP.
- Separar captación, despacho, inventario, reutilización y valorización verificada.
- Trabajar inicialmente con **pesaje manual**, sin obligar sensores.
- Medir cobertura y calidad de datos, no solo kilogramos.
- Implementar recomendaciones simples basadas en reglas verificables.
- Probar operación con personas ajenas al equipo de desarrollo.
- Documentar la transferencia al Hub para que el sistema pueda mantenerse.

## Orden de implementación más seguro

1. Levantar datos y acordar piloto con la contraparte.
2. Cerrar requisitos, protocolo y reglas de negocio.
3. Construir registro completo de pesaje hasta base de datos.
4. Añadir lote, saldos y movimientos.
5. Crear indicadores alimentados por esos registros.
6. Agregar recomendaciones, exportaciones y pruebas de facilidad de uso.
7. Evaluar el piloto y presentar resultados documentados.

## Próximo artefacto técnico recomendado

Desarrollar un **Documento de Especificación de Requisitos de Software (SRS)** con historias de usuario, casos de uso, diagramas entidad-relación, restricciones, contratos de API, criterios de aceptación, flujo de navegación y matriz de pruebas. Ese documento servirá como base para repartir tareas de implementación sin interpretaciones diferentes.
